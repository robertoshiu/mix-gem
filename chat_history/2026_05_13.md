  value: number;

## Section 7: Babylon.js Scene Technical Details

**Scene setup (`FabFloorScene.tsx`):**

- **Engine**: `WebGPU` with `WebGL2` fallback (same pattern as existing `FabTwinBabylonScene`)
- **GlowLayer**: intensity 0.6, blur kernel 32 — drives the cyberpunk emissive look
- **ShadowGenerator**: `CascadedShadowGenerator` on one directional light, 1024px map
- **PostProcess**: `DefaultRenderingPipeline` with bloom (threshold 0.8) + chromatic aberration (0.3) + grain (0.04)

**Station mesh construction (procedural, no external glTF):**

Each station built from Babylon.js primitives:

```
Oxidation:    Cylinder (furnace tube) + Torus (coil rings) + Box (wafer boat)
Lithography:  Box (scanner body) + Cylinder (illumination column) + Plane (reticle stage)
Etching:      Cylinder (chamber) + Sphere (dome lid) + Tubes (gas lines)
Deposition:   Cylinder×2 (twin chambers) + Disc (showerhead) + Torus (plasma ring)
Ion Implant:  Box (beamline) + Cylinder (acceleration tube) + ParticleSystem (beam)
Diffusion:    Cylinder (vertical furnace) + Cylinder (quartz tube, transparent)
CMP:          Disc (platen) + Cylinder (polish head) + ParticleSystem (slurry)
Metallization: Box (sputter body) + Disc (target) + Plane (wafer chuck)
```

**Materials:** `PBRMaterial` per station — base color dark gray (`#1a1a2e`), `emissiveColor` set to process color, `emissiveIntensity` modulated by state (0.3 idle, 0.8 selected, pulsing on alarm).

**Performance targets:**
- Total triangle budget: ~50K across all 8 stations + conveyor + floor
- LOD: 2 levels per station (LOD0 full detail < 20m, LOD1 simplified > 20m)
- Instancing: conveyor rail segments, floor hex tiles
- Target: 60fps on integrated GPU (Intel UHD 770)

**Conveyor animation:**
- `TransformNode` path following a U-shape spline (`CatmullRomSpline`, 16 control points)
- 3–5 FOUP carriers on the path simultaneously, each `lerp`-ing along the spline
- Carrier emissive color blends between current station color and next station color during transit
- Dwell time at each station: 1.5s (visual only, not real process time)
