## Section 4: 警報與 AR 第一人稱視角切換

**警報觸發流程：**
1. 人員進入禁區 → AABB 碰撞偵測命中
2. 建立警報物件 `{ id, personnelId, zoneId, timestamp, position, acknowledged: false }`
3. 推送到 Zustand store 的 `alerts[]` 陣列
4. 場景內該禁區邊框變為實線 + 加強紅色脈衝
5. 畫面左上角彈出浮動 toast（復用現有 alert 嚴重度配色：CRITICAL 紅色），顯示「⚠ OP-02 entered HV-ZONE」

**點擊警報 → 切換 AR 視角：**
1. 點擊 toast 或 HUD 面板上的警報項目
2. 在該人員頭部位置建立 `TargetCamera`（或 `UniversalCamera`），高度 1.7（眼睛位置），朝向人員面對的方向
3. `scene.activeCamera` 切換為該 FPS 相機，加入 easing 過渡動畫（0.5 秒）
4. 進入 AR 視角後，畫面四周疊加半透明綠色 AR HUD 邊框（用 `GUI.Rectangle` 或 React overlay），模擬 AR 眼鏡效果
5. 顯示該人員前方設備的名稱標籤（billboard）和距離資訊

**返回俯瞰視角：**
- 畫面上出現「← Back to Overview」按鈕，點擊切回 `ArcRotateCamera`
- 或按 `ESC` 鍵返回

## Section 6: 狀態管理 — Zustand Store

```typescript
// ar-tracking-store.ts
interface Personnel {
  id: string;              // "OP-01"
  name: string;            // "Chen Wei"
  waypointIndex: number;   // 當前路徑點索引
  position: [number, number]; // XZ 座標
  inZone: string | null;   // 當前所在禁區 ID 或 null
  status: 'normal' | 'violation';
}

interface Alert {
  id: string;
  personnelId: string;
  zoneId: string;
  zoneName: string;
  timestamp: number;
  acknowledged: boolean;
}

interface ArTrackingState {
  personnel: Personnel[];
  alerts: Alert[];
  activeView: 'overview' | { type: 'ar'; personnelId: string };
  
  // Actions
  triggerAlert: (personnelId: string, zoneId: string) => void;
  acknowledgeAlert: (alertId: string) => void;
  switchToArView: (personnelId: string) => void;
  switchToOverview: () => void;
}
```

**場景與 Store 的互動：** Babylon.js 的 render loop 每幀更新人員位置並寫入 store。React HUD 元件透過 `useArTrackingStore` 訂閱狀態變化，渲染警報和人員清單。視角切換由 React 觸發 → store 更新 `activeView` → 場景在下一幀讀取並切換攝影機。
