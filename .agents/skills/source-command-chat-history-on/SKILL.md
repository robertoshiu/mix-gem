# source-command-chat-history-on

Use this skill when the user asks to run the migrated source command `chat-history-on`.

## Command Template

Create the file `.Codex/chat-history-enabled` with the content "enabled" to enable chat history logging.

After creating the file, respond with: "Chat history logging is now ON. All messages will be saved to `chat_history/YYYY_MM_DD.md`"
